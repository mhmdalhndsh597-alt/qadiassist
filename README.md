# مِعيار — مساعد ملف القضية

مساحة عربية لتنظيم مستندات القضية وإنتاج مسودة أولية قابلة للتحقق من مصدرها. لا يقدم التطبيق رأيًا قانونيًا أو بحثًا قانونيًا، وكل مخرج آلي يحتاج إلى مراجعة محامٍ.

## حالة المشروع

هذا إصدار تجريبي مبكر. استخدم ملفات اصطناعية أو منزوعة الهوية فقط. المستندات والنصوص تنتقل إلى خدمات Manus لتخزين الملفات وقاعدة البيانات والتحليل عند موافقة المستخدم. واجهة تخزين الملفات الحالية لا توفر حذفًا ماديًا للكائن من التطبيق؛ حذف الملف في هذه النسخة يزيله من مساحة العمل ويزيل نصه ومراجعه، لكنه لا يثبت محو البايتات من مخزن الكائنات. لا ترفع ملفات قضايا فعلية أو بيانات شخصية إلى المعاينة.

## التشغيل

يتطلب Node.js 22 أو أحدث وpnpm 11.25.0. في بيئة Manus WebDev تتم تهيئة متغيرات خدمات المنصة تلقائيًا.

```bash
pnpm install
pnpm db:migrate
pnpm dev
```

يعرض التطبيق واجهته وواجهات API عبر المنفذ `PORT` أو 3000. انسخ `.env.example` إلى `.env` للتشغيل المحلي بعد إعداد قيم الخدمات بشكل آمن؛ لا تضع القيم الحقيقية في Git. ترحيلات قاعدة البيانات محفوظة في `migrations/` ويمكن توليد ترحيل جديد عبر `pnpm db:generate` بعد تعديل مخطط Drizzle.

## النطاق الأولي

يدعم الإصدار التجريبي PDF وDOCX، واستخراج النص والإحالات، وتحليلًا متوازيًا بثلاثة أدوار: ملخص، وخط أحداث، وأطراف/كيانات. يدمج الخادم النتائج الجزئية ويتحقق من أن الاقتباس موجود حرفيًا وأن معرّف المقطع صالح قبل حفظ المسودة. هذا التحقق لا يثبت أن الاقتباس يسند الاستنتاج دلاليًا؛ راجع كل نتيجة في موضعها من المستند قبل الاعتماد. أرقام صفحات PDF دقيقة حسب ما يعيده محلل النص؛ أما DOCX فيستخدم مراجع المقاطع عند تعذر معرفة رقم الصفحة من المصدر. لا يقوم النظام ببحث قانوني، أو OCR للمسح الضوئي، أو تقييم لصحة الادعاءات. اختبارات الوكلاء لا تتصل بالنموذج؛ أما التشغيل الحي فقد يستهلك حتى ستة طلبات (ثلاثة تشغيل وثلاث محاولات إصلاح، واحدة لكل وكيل).

## تعاون المجتمع ومستودعات Git


المصدر العام [qadiassist على GitHub](https://github.com/mhmdalhndsh597-alt/qadiassist) أُنشئ برخصة MIT، ودُفع إليه الفرع `main`. المستودع الخاص المقترح `qadiassist-private` مخصص للتخصيص والعمل اليومي. هدف الربط هو جعل العام `upstream` والخاص `origin`: تُجلب التحديثات العامة إلى الخاص للمعاينة ثم تدمج صراحةً عبر `./scripts/sync-upstream.sh --merge` بعد المراجعة، فيما تُرسل مساهمات المجتمع عبر فروع وPull Request. لا تُدفع التخصيصات الخاصة إلى العام تلقائيًا. لا تستخدم `--force` ولا ترفع أسرارًا أو ملفات قضايا. نقل المشروع إلى المستودع الخاص ينتظر تأكيد بطاقة GitHub الرسمية؛ إلى أن يكتمل النقل يبقى `origin` هو المستودع المُدار من Manus. راجع [دليل مزامنة المستودعين](docs/repository-workflow.md).

## التحقق والجودة

```bash
pnpm typecheck
pnpm test
pnpm build
```

تستخدم اختبارات المشروع بيانات اصطناعية فقط. لا تشغّل اختبارًا يكتب أو يحذف بيانات قضية حقيقية على قاعدة البيانات المدارة؛ قاعدة التطوير والنشر قد تكون مشتركة.
