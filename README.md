# مِعيار — مساعد ملف القضية

مساحة عربية لتنظيم مستندات القضية وإنتاج مسودة أولية قابلة للتحقق من مصدرها. لا يقدم التطبيق رأيًا قانونيًا أو بحثًا قانونيًا، وكل مخرج آلي يحتاج إلى مراجعة محامٍ.

## حالة المشروع

هذا إصدار تجريبي مبكر. استخدم ملفات اصطناعية أو منزوعة الهوية فقط. المستندات والنصوص تنتقل إلى خدمات Manus لتخزين الملفات وقاعدة البيانات والتحليل عند موافقة المستخدم. واجهة تخزين الملفات الحالية لا توفر حذفًا ماديًا للكائن من التطبيق؛ حذف الملف في هذه النسخة يزيله من مساحة العمل ويزيل نصه ومراجعه، لكنه لا يثبت محو البايتات من مخزن الكائنات. لا ترفع ملفات قضايا فعلية أو بيانات شخصية إلى المعاينة.

## التشغيل

يتطلب Node.js 22 أو أحدث وpnpm 11.25.0. في بيئة Manus WebDev تتم تهيئة متغيرات خدمات المنصة تلقائيًا.

```bash
pnpm install
pnpm db:migrate
pnpm dev
```

يعرض التطبيق واجهته وواجهات API عبر المنفذ `PORT` أو 3000. انسخ `.env.example` إلى `.env` للتشغيل المحلي بعد إعداد قيم الخدمات بشكل آمن؛ لا تضع القيم الحقيقية في Git. ترحيلات قاعدة البيانات محفوظة في `migrations/` ويمكن توليد ترحيل جديد عبر `pnpm db:generate` بعد تعديل مخطط Drizzle.

## النطاق الأولي

يدعم الإصدار التجريبي PDF وDOCX، واستخراج النص والإحالات، والمسودة والجدول الزمني والأسماء. أرقام صفحات PDF دقيقة حسب ما يعيده محلل النص؛ أما DOCX فيستخدم مراجع المقاطع عند تعذر معرفة رقم الصفحة من المصدر. لا يقوم النظام ببحث قانوني، أو OCR للمسح الضوئي، أو تقييم لصحة الادعاءات.

## تعاون المجتمع ومستودعات Git

الخطة التي أقرها المستخدم هي مصدر عام باسم `qadiassist` برخصة MIT ومستودع خاص باسم `qadiassist-private` للتخصيص. المقصود أن يكون العام `upstream` والخاص `origin`: تُجلب التحديثات العامة إلى الخاص للمعاينة ثم تدمج صراحةً عبر `./scripts/sync-upstream.sh --merge` بعد المراجعة، فيما تُرسل مساهمات المجتمع عبر فروع وPull Request. لا تُدفع التخصيصات الخاصة إلى العام تلقائيًا. لا تستخدم `--force` ولا ترفع أسرارًا أو ملفات قضايا. إنشاء العام والتحقق من وجهة الحساب وربط الاثنين جارٍ؛ نقل المستودع الخاص ينتظر تأكيد بطاقة GitHub المعلّقة. راجع [دليل مزامنة المستودعين](docs/repository-workflow.md).

## التحقق والجودة

```bash
pnpm typecheck
pnpm test
pnpm build
```

تستخدم اختبارات المشروع بيانات اصطناعية فقط. لا تشغّل اختبارًا يكتب أو يحذف بيانات قضية حقيقية على قاعدة البيانات المدارة؛ قاعدة التطوير والنشر قد تكون مشتركة.

## المساهمة والأمن

راجع `CONTRIBUTING.md` و`SECURITY.md`. تجنب إرسال بيانات قضايا أو أسرار إلى Issues أو Pull Requests. أبلغ عن ثغرة أمنية عبر قناة خاصة بمالك المشروع بدل نشر تفاصيل الاستغلال علنًا.
