# ربط المستودع العام والخاص

هذا المشروع يفصل بين مصدر عام للمساهمات ومساحة خاصة للتخصيص. لا تضع بيانات القضايا أو مفاتيح الخدمة في أي مستودع.

في مجلد العمل الخاص، أضف رابط المصدر العام مرة واحدة باسم `upstream`:

```bash
git remote add upstream <URL_OF_PUBLIC_SOURCE>
git fetch upstream
```

لمعاينة التحديثات الواردة من المصدر العام دون تعديل الفرع المحلي:

```bash
./scripts/sync-upstream.sh
```

بعد مراجعة سجل التغييرات، يمكن دمجها بوضوح عبر:

```bash
./scripts/sync-upstream.sh --merge
```

إذا ظهر تعارض، أوقف الدمج وحلّه يدويًا ثم شغّل الاختبارات. ادفع الدمج إلى المستودع الخاص فقط بعد المراجعة:

```bash
pnpm typecheck && pnpm test && pnpm build
git push origin main
```

للمساهمة في المشروع العام، أنشئ فرعًا منفصلًا وأرسل Pull Request؛ لا ترفع تعديلاتك الخاصة مباشرةً إلى `upstream/main`. لا يستخدم هذا المسار `--force` أو مزامنة تحذف ملفات. تبقى الوجهات الفعلية للمستودعين بحاجة إلى تأكيد المالك قبل إنشاء أي مستودع.
